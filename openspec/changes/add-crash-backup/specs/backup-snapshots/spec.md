# Spec Delta

## Purpose

定义 DSH 环境备份的产出形态：每次备份生成一个可独立保存、独立恢复的压缩存档，其内容、命名、可见性和数量边界对用户与恢复脚本都是稳定契约。

## ADDED Requirements

### Requirement: 每份存档是独立文件夹

系统 SHALL 在备份根目录下为每次备份创建一个独立文件夹，文件夹名唯一标识存档并包含创建时间，不得把多份存档写进同一个文件夹。

#### Scenario: 备份完成后生成独立文件夹
- **WHEN** 用户在设置页点击"备份当前环境"且备份成功
- **THEN** 备份根目录下出现一个新的存档文件夹，名称包含 `dsh-save-` 前缀与本地时间戳
- **AND** 再次备份会创建另一个文件夹，不会覆盖或合并已有存档

### Requirement: 存档文件夹只包含压缩包和恢复脚本

系统 SHALL 让每个存档文件夹内只包含一个压缩包与恢复脚本文件，不得在该文件夹写入日志、清单、临时文件或其它辅助文件。

#### Scenario: 检查存档文件夹内容
- **WHEN** 一份备份成功完成
- **THEN** 该文件夹内只有压缩包、恢复入口脚本和恢复脚本实现文件
- **AND** 备份过程中的临时文件不出现在最终文件夹中

### Requirement: 压缩包保存完整环境与插件信息

系统 SHALL 把 DSH 安装目录、插件 profile（含 node_modules 与 lock 文件）、其它 profile 的配置文件、用户目录中的配置与数据、运行时依赖，以及一份描述版本与插件清单的 `manifest.json` 写入压缩包。

#### Scenario: 解压后得到完整结构
- **WHEN** 用户解压任一新格式存档的压缩包
- **THEN** 压缩包内包含 `install/`、`profile/`、`home/`、`runtimes/` 与 `manifest.json`
- **AND** `manifest.json` 记录 DSH 版本、创建时间、profile 名称、插件依赖清单与总体积

#### Scenario: 用户名或路径含中文
- **WHEN** DSH 安装目录或用户目录的路径包含中文、空格或非 ASCII 字符
- **THEN** 解压后文件名与目录名保持原样，不出现乱码或被替换为问号

### Requirement: 备份完成前存档不可见

系统 SHALL 先把压缩包写入临时文件，只有在压缩包与恢复脚本全部写入成功后才把存档文件夹变为正式状态；任何中断都不得产生可被列表识别为完整的存档。

#### Scenario: 备份中途失败
- **WHEN** 备份在压缩或写脚本阶段失败或被中断
- **THEN** 列表不显示该存档，用户也无法从该存档发起回档
- **AND** 残留的临时文件可以被后续备份流程识别并清理

### Requirement: 备份前执行环境校验

系统 SHALL 在开始备份前检查安装目录与 profile 是否存在、备份目录是否可用、磁盘剩余空间是否足够，并在任一条件不满足时拒绝备份并返回可读原因。

#### Scenario: 磁盘空间不足
- **WHEN** 备份目录所在磁盘的剩余空间低于完成一次备份所需
- **THEN** 系统拒绝开始备份并提示剩余空间不足
- **AND** 不创建新的存档文件夹

#### Scenario: 已有备份任务进行中
- **WHEN** 上一份备份尚未结束，用户再次触发备份
- **THEN** 系统拒绝新任务并提示已有任务正在进行

### Requirement: 存档数量受上限约束

系统 SHALL 把同时保留的存档数量限制在一个固定上限内，达到上限后拒绝新建备份并提示用户先删除旧存档。

#### Scenario: 达到上限
- **WHEN** 已保存的存档数量等于上限，用户再次点击备份
- **THEN** 系统拒绝备份并提示先删除一个存档
- **AND** 已有存档不受影响

### Requirement: 存档索引可由文件夹重建

系统 SHALL 在备份根目录维护一份存档索引用于列表展示，并保证索引缺失、损坏或与文件夹不一致时可以通过扫描存档文件夹重建，不丢失任何可恢复的存档。

#### Scenario: 索引被删除
- **WHEN** 用户手动删除备份根目录下的索引文件后打开设置页
- **THEN** 列表仍然显示所有新格式存档
- **AND** 索引被重新生成

#### Scenario: 旧格式存档存在
- **WHEN** 备份根目录中存在旧版 `payload` 目录格式的存档
- **THEN** 新插件不把它识别为可回档存档，也不删除或迁移它
