# plugin-rollback Specification
## Purpose

定义在完整回档之外只恢复插件 profile 的回档模式：用户可以在设置页或恢复脚本中选择该模式，把插件定义、锁文件、patch 与 node_modules 恢复到存档时，同时明确保证 DSH 安装目录与用户数据不被触碰。

## Requirements
### Requirement: 设置页提供回档模式选择

设置页 SHALL 在用户对某个存档发起回档时，提供「完整回档」与「仅回滚插件」两个选项，并在选择前说明两者的恢复范围差异。

#### Scenario: 选择仅回滚插件
- **WHEN** 用户在回档弹窗中选择「仅回滚插件」并确认
- **THEN** 系统以仅插件模式启动恢复脚本
- **AND** 弹窗说明只恢复插件、不改动 DSH 安装与用户数据

#### Scenario: 选择完整回档
- **WHEN** 用户选择「完整回档」
- **THEN** 系统按完整回档流程启动恢复脚本

### Requirement: 恢复脚本启动时先选择模式

恢复脚本 SHALL 在不带模式参数启动时，先显示模式菜单（`1` 完整回档、`2` 仅回滚插件），收到有效输入后再进入确认步骤；带模式参数启动时跳过菜单并显示所选模式。

#### Scenario: 双击脚本
- **WHEN** 用户双击恢复脚本且未带参数
- **THEN** 脚本显示模式菜单并等待输入
- **AND** 输入 `1` 或 `2` 后显示对应模式与存档信息

#### Scenario: 从设置页触发
- **WHEN** 设置页以仅插件模式启动脚本
- **THEN** 脚本跳过模式菜单，直接显示"仅回滚插件"与确认提示

#### Scenario: 模式输入无效
- **WHEN** 用户输入菜单以外的内容
- **THEN** 脚本提示输入无效并重新显示菜单，或按取消处理

### Requirement: 仅插件模式只恢复插件 profile

仅插件模式 SHALL 只写入插件 profile 目录（`package.json`、`pnpm-lock.yaml`、`cordis.patch.yml`、`node_modules` 等），不得写入 DSH 安装目录、用户目录或运行时依赖目录。

#### Scenario: 安装目录保持不变
- **WHEN** 仅插件回档完成
- **THEN** DSH 安装目录中的文件内容与回档前一致
- **AND** 不出现因镜像恢复而被删除的新版文件

#### Scenario: 用户数据保持不变
- **WHEN** 仅插件回档完成
- **THEN** 用户目录中的会话、技能、凭据与插件数据目录未被覆盖或删除

#### Scenario: 插件恢复为存档时状态
- **WHEN** 仅插件回档完成
- **THEN** 插件 profile 的包定义、锁文件、patch 与 node_modules 与存档一致
- **AND** 存档之后新增的其它插件文件被移除

### Requirement: 仅插件模式只解压插件部分

仅插件模式 SHALL 只从压缩包中解压 profile 部分，不把整个压缩包解压到临时目录，以减少恢复所需空间与时间。

#### Scenario: 解压范围受限
- **WHEN** 脚本以仅插件模式执行解压
- **THEN** 临时目录中只出现 profile 相关内容
- **AND** 不产生安装目录或用户目录的解压副本

### Requirement: 仅插件模式快照范围限于插件

仅插件模式 SHALL 在覆盖前只把当前插件 profile 的关键配置保存到带时间戳的快照位置，不复制安装目录或用户目录。

#### Scenario: 回档前快照
- **WHEN** 仅插件模式通过校验并开始覆盖
- **THEN** 当前 profile 的 package.json、锁文件与 cordis.patch.yml 已保存到快照目录
- **AND** 快照失败时脚本中止，不继续覆盖

### Requirement: 仅插件模式提示不回退的范围

仅插件模式 SHALL 在执行前提示：插件数据目录、DSH 版本与用户配置不会回退；当存档的 DSH 版本与当前版本不一致时，SHALL 额外提示插件可能存在兼容性风险，并允许用户取消。

#### Scenario: 插件数据不回退
- **WHEN** 用户选择仅插件模式
- **THEN** 脚本与设置页都提示插件数据与用户配置保持当前状态

#### Scenario: DSH 版本不一致
- **WHEN** 存档记录的 DSH 版本与当前运行版本不同
- **THEN** 脚本显示版本差异与兼容性风险
- **AND** 用户仍可继续或取消

### Requirement: 仅插件模式沿用回档保护规则

仅插件模式 SHALL 沿用完整回档的插件自身保护与链接重建规则：恢复 profile 时排除本插件目录，并在恢复后按存档记录重建本地依赖链接。

#### Scenario: 插件自身保留
- **WHEN** 仅插件回档完成
- **THEN** 本插件目录仍然存在
- **AND** 若目录缺失，脚本提示重新安装

#### Scenario: 本地依赖链接
- **WHEN** 存档记录到某个插件依赖是本地链接
- **THEN** 仅插件回档后该依赖仍是指向原路径的目录链接

### Requirement: 仅插件模式结束提示重启

仅插件模式 SHALL 在成功、取消、失败三条路径结束时提示结果，成功时提示需要重启 DSH 才能加载回档后的插件，并等待任意键后退出。

#### Scenario: 仅插件回档成功
- **WHEN** 仅插件回档完成
- **THEN** 脚本提示插件已恢复、需要重启 DSH
- **AND** 等待任意键后退出

### Requirement: 存档不支持仅插件模式时禁用选项

当存档缺少插件 profile 内容时，设置页 SHALL 禁用「仅回滚插件」选项并说明原因，脚本 SHALL 拒绝以仅插件模式执行。

#### Scenario: 存档内容不完整
- **WHEN** 存档的压缩包中不存在 profile 内容
- **THEN** 设置页的仅插件选项不可选并显示原因
- **AND** 脚本收到仅插件参数时报错退出，不修改任何文件
